# 🇵🇰 FormSathi AI

## Samjho. Bharo. Submit Karo.

FormSathi AI is a Generative AI powered multilingual form assistant designed to help people understand and complete complicated forms.

## Features

- Upload PDF or image forms
- AI form analysis
- Field-by-field explanations
- English, Urdu and Roman Urdu
- Required document checklist
- Missing/unclear information detection
- Step-by-step guidance
- AI chat about the uploaded form

## Technology

- Python
- Gradio
- OpenAI API
- PyMuPDF
- OCR/vision-capable AI
- Generative AI

## Social Impact

Many people struggle with complicated forms because of difficult language and confusing instructions.

FormSathi AI aims to make important forms easier to understand, especially for people who are more comfortable with Urdu or Roman Urdu.
